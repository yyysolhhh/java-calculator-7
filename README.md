# java-calculator-precourse

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

### 요구 사항

- [ ] 입력 프롬프트 출력
- [ ] 입력
    - [ ] 구분자(쉼표 또는 콜론)와 양수로 구성된 문자열
    - [ ] 기본 구분자 외 커스텀 구분자(//와 \n 사이에 위치하는 문자)
    - [ ] 잘못된 값 입력 시 IlLegaLArgumentException 발생시킨후 애플리케이션 종료
- [ ] 구분자를 기준으로 문자열을 숫자로 분리
- [ ] 각 숫자의 합 반환
- [ ] 출력
    - [ ] 덧셈 결과
